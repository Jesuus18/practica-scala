# Parte 3: Mini proyectos con Scala

Aplicamos funciones, colecciones y condicionales en dos programas. En ambos usamos Scala 2.12.21 y JDK 17. Compilamos y ejecutamos con sbt desde la terminal del editor.

## Parte 3.1: Torneo de Twenty-One

Trabajamos en Visual Studio Code con Metals. Analizamos dos rondas, contamos las manos válidas y comparamos las mejores puntuaciones. Recorremos las puntuaciones con `while` y añadimos una versión con `foreach`.

- [Documentación y capturas](../workspace/torneo-twenty-one/README.md).
- [Código de Main.scala](../workspace/torneo-twenty-one/src/main/scala/Main.scala).
- [Configuración build.sbt](../workspace/torneo-twenty-one/build.sbt).

## Parte 3.2: Analizador de notas

Trabajamos en IntelliJ IDEA. Clasificamos las notas de cinco estudiantes, calculamos los resúmenes de dos evaluaciones y comparamos el número de aprobados. También creamos una lista con un estudiante nuevo sin modificar la original.

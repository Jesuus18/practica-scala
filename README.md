# Práctica de programación básica con Scala

Configuramos tres entornos de trabajo con Scala y resolvemos quince ejercicios de programación en JupyterLab.

## Autor

Jesús Martínez de la Casa

## Entorno utilizado

- Sistema operativo: Windows 11.
- Scala: 2.12.21.
- Java: Azul Zulu JDK 17.0.20.1.

| Entorno | Herramientas utilizadas |
| --- | --- |
| JupyterLab | Python 3.12.10, JupyterLab 4.6.3 y Almond 0.14.5. Abrimos JupyterLab en Google Chrome |
| Visual Studio Code | VS Code 1.137.0, extensión Scala (Metals) 1.71.0 y sbt 1.13.0 |
| IntelliJ IDEA Community | IntelliJ 2024.3.1.1, plugin Scala 2024.3.35 y sbt 1.10.3 |
